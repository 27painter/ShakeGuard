# 摇一摇克星 · 放行名单（登录 / 支付 / 授权关键域名）
#
# 为什么需要这份名单：
#   广告规则库里偶尔会混进「登录跳转」所依赖的域名。一旦被拦成 0.0.0.0，
#   就会出现「点微信/QQ/支付宝登录，跳过去又弹回来」「授权页一片空白」这类怪现象。
#
# 匹配规则（比拦截规则更强势，永远优先）：
#   1) 本文件里的域名及其所有子域名，永不拦截；
#   2) 本文件里域名的「上级域名」也一起放行 —— 例如写了 graph.qq.com，
#      那么即使规则库里有人拦 qq.com，也不会波及登录；
#   3) 域名里带 login / passport / oauth / sso / openapi / verify / captcha /
#      wallet / pay 这类词的，默认也不拦（可在 App 里关掉「登录跳转保护」）。
#
# 用户自己添加的放行域名写在 files/rules_allow.txt，格式同样是「一行一个域名」。
